# Changelog

## [0.2.0]

### Added

- First release: Solar Icon Set main, 2026-10 as a Poetry icon set, 8,706 icons registered as `:solar`, `:solar_bold`, `:solar_bold_duotone`, `:solar_broken`, `:solar_line_duotone`, `:solar_outline`. Each style is one packed file of sanitized inner markup, served by poetry-core's `Icons::PackedSet` with its own drawing attributes.
