# Changelog

## [0.2.0]

### Added

- First release: Phosphor Icons v2.0.8 as a Poetry icon set, 7,488 icons registered as `:phosphor`, `:phosphor_bold`, `:phosphor_duotone`, `:phosphor_fill`, `:phosphor_light`, `:phosphor_thin`. Each style is one packed file of sanitized inner markup, served by poetry-core's `Icons::PackedSet` with its own drawing attributes.
