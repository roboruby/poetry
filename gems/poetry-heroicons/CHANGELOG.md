# Changelog

## [0.2.0]

### Added

- First release: Heroicons v2.2.0 as a Poetry icon set, 1,288 icons registered as `:heroicons`, `:heroicons_solid`, `:heroicons_mini`, `:heroicons_micro`. Each style is one packed file of sanitized inner markup, served by poetry-core's `Icons::PackedSet` with its own drawing attributes.
